# Migrating from 0.7.x to 0.8.0

0.8.0 adopts ADR-0009 (Wolfgang.Etl.Abstractions 0.24.0): a loader is configured through an options record passed to
its constructor, not through setters after construction. No loader member is removed in this release; the setters
are `[Obsolete]` and still work. The one removal is the `ISupportDryRun` interface implementation, which
Abstractions 0.24.0 drops (see below).

## Configure through `SqlBulkCopyLoaderOptions<T>`

```csharp
// 0.7.x
var loader = new SqlBulkCopyLoader<Customer>(connection)
{
    BatchSize = 10_000,
    PreAction = PreAction.TruncateTable,
    IsDryRun = rehearsal,
};

// 0.8.0
var loader = new SqlBulkCopyLoader<Customer>
(
    connection,
    new SqlBulkCopyLoaderOptions<Customer>
    {
        BatchSize = 10_000,
        PreAction = PreAction.TruncateTable,
        IsDryRun = rehearsal,
    }
);
```

Every settable property on the loader has a member of the same name and default on the record, so an object
initializer moves across unchanged. The record also carries the settings every loader shares (`ReportingInterval`,
`MaximumItemCount`, `SkipItemCount`, `ErrorPolicy`), and `BulkCopyOptions` for the `SqlBulkCopyOptions` flags.

## `SqlBulkCopyOptions` and the transaction

```csharp
// 0.7.x
new SqlBulkCopyLoader<Customer>(connection, SqlBulkCopyOptions.TableLock, transaction, logger);

// 0.8.0 (the old overload still binds; new code puts the flags on the record)
new SqlBulkCopyLoader<Customer>(connection, new SqlBulkCopyLoaderOptions<Customer> { BulkCopyOptions = SqlBulkCopyOptions.TableLock }, transaction, logger);
```

The transaction stays a constructor parameter. Options, transaction and logger are all optional, so a logger can be
supplied on its own: `new SqlBulkCopyLoader<Customer>(connection, logger: logger)`.

## `ISupportDryRun`

`SqlBulkCopyLoader<T>` no longer implements `ISupportDryRun`, which Abstractions 0.24.0 removes. `IsDryRun` is still
readable on the loader; set it through the record. Code that tested for the interface (`loader is ISupportDryRun`)
should read the property instead.

## Deprecated

The setter of every configurable property on the loader (`BatchSize`, `BulkCopyTimeout`, `DestinationTableName`,
`DestinationSchemaName`, `EnableDataValidation`, `IsDryRun`, `ValidationFailureBehavior`, `OnValidationFailed`,
`OnNestedValidationFailed`, `PreAction`, `PreLoadCustomAction`, `PostAction`, `PostLoadCustomAction`) is `[Obsolete]`
on the setter accessor; reads stay warning-free. They will be removed in a later release.
