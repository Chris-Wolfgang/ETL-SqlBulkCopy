Class-named SQL Server sink terminator for the fluent Wolfgang.Etl.Abstractions.EtlPipeline chain. The terminator constructs a SqlBulkCopyLoader<TRecord>(IEtlPipeline<TRecord>, SqlConnection, SqlBulkCopyLoaderOptions<TRecord>?, SqlTransaction?, ILogger<SqlBulkCopyLoader<TRecord>>?) and terminates the pipeline, so any source package can flow straight into a bulk insert.

Remarks

The caller owns SqlConnection and any SqlTransaction: the sink never opens, closes or disposes them, exactly as when the loader is constructed directly.
